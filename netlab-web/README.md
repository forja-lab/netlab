# NetLab web

Versión web de NetLab para iPad, iPhone y cualquier navegador. No necesita el Mac ni servidor propio.

- Medición de bajada, subida, latencia, jitter, latencia bajo carga y DNS por HTTPS (servidores de Cloudflare).
- Mapa de calor por habitaciones con plano, exportable como proyecto.
- Informes guardados en el dispositivo, con exportación e importación en JSON y comparación entre dispositivos con diagnóstico.
- Instalable como app (Safari: Compartir → Añadir a pantalla de inicio) y utilizable sin conexión.

Todo se guarda solo en el navegador del dispositivo. No hay cuentas ni recolección de datos.

## Publicar en GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)`. La dirección será `https://<organización>.github.io/<repositorio>/`.
